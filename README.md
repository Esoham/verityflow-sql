# VerityFlow — SQL Data Quality & Reporting

Independent portfolio demonstration with synthetic mortgage operations data. SQL reconciliation, exception detection, and operational reporting. No real customer information.

## Run
`python run.py` (Python 3, SQLite included).

## Contents
- `schema.sql`, `seed.sql`: schema and fictional sample records
- `quality_checks.sql`: duplicate, invalid amount, missing agent and workflow checks
- `reporting.sql`: management reporting queries
- `demo_output.txt`: illustrative output

This is not affiliated with any lender or mortgage company. Production systems would require validated definitions, access controls, privacy protections, monitoring and human review.
